## 一、如何打开

1. 双击本目录下的 `index.html`（推荐 Chrome / Edge / Firefox）。
2. 首次进入为全屏中国版图首页，右上角为背景音乐面板（默认音量 25%，浏览器会限制自动播放，点击页面任意位置或播放键即可响起）。
3. 点击【开始规划行程】→ 选省选市 → 依次完成 地点 / 时间 / 人物 三个模块 → 生成行程台账。

> 音乐文件：`assets/audio/pingfan-zhilu.mp3`（朴树《平凡之路》，单曲循环）。

## 三、约束推理逻辑（答辩重点）

约束优先级固定为：**人物约束 ＞ 地点偏好 ＞ 时间偏好**，每一次自动改动都会写入「全部修改归因记录」标签页。

引擎实现在 `js/engine.js`，主要规则：

- 行程强度自适应：含 60 岁以上老人 / 行动不便成员 / 体力偏弱时，紧凑打卡自动降级，逐级记录「原值 → 新值」；
- 景点适配：带「爬坡 / 台阶 / 长步行」标签的点位在老人、行动障碍成员在场时被同城平缓点位替换或移出；
- 交通过滤：有人不会骑车 → 剔除共享单车 / 电驴；有成员晕车 → 减少长时间跨区赶路；
- 餐饮过滤：过敏源（海鲜 / 坚果 / 乳制品 / 麸质…）与忌口逐道菜品剔除，并生成「避雷清单」；
- 天气预案：开启自动替换时，雨天 / 高温把户外点位替换为同城室内备选，并在时间轴标注【预案替换】；
- 开放状态：周一闭馆点位自动换序；
- 收工时间：超过每日最晚收工时间则取消夜游并记录；
- 首尾约束：首日上午抵达 / 返程日上午离开等会直接压缩当日可游时段；
- 预算校正：人均总预算低于测算时，自动降级住宿与门票支出并说明原因。

演示建议：在人物模块勾选「60 岁以上老人 + 3–12 岁儿童」、勾选「坚果过敏」、时间模块选「紧凑打卡」、天气选「开启自动替换」，即可在归因页看到 10 条以上的自动调整链路。

## 五、说明与边界

- **图片**：全部由 `art.js` 程序化绘制（天空晕染、三层远山、云气、水面、飞檐古建、松林、舟楫），不使用任何实拍照片，符合「中式山水油画质感」要求。
- **数据**：63 座城市收录真实知名景点；其余城市使用通用样本点位并在页面标注「通用样本点位」，仅用于演示排线逻辑。餐厅、酒店名称为示例方案，票价、车程、房价均为估算值。
- **PDF**：点击【导出 PDF 台账】调起浏览器打印，选择「另存为 PDF」即可；版式含封面、目录、8 个章节与全部约束参数附录，导出时背景音乐自动静音。
- **兼容**：Chrome / Edge / Firefox 现代版本；采用传统脚本加载（非 ES Module），因此 `file://` 直接双击打开不会触发跨域限制。
- **离线**：不依赖任何 CDN 或网络请求，断网可用。
